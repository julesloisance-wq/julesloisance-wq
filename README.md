### Finding the same microscopic track on two instruments

At the Helsinki Institute of Physics, I refactored a Python pipeline that detects ion tracks in microscope scans and helps researchers locate them again on a 3D profilometer. The full workflow went from about three hours to ten minutes, with targeting precision under 50 µm.

[Explore the vision pipeline](https://github.com/julesloisance-wq/NTD-ellipses) · [Read the detection code](https://github.com/julesloisance-wq/NTD-ellipses/blob/main/ellipse_detection.py)

### AeroDoc — can a maintenance question be answered from the source?

I designed and evaluated a retrieval-augmented assistant for FAA maintenance documents, with code written using Claude Code. On 22 answerable held-out questions, AeroDoc answered 18 correctly, compared with 6 for the language model alone. The demo also shows what happens when a requested directive is missing.

[Watch the 30-second demo](https://github.com/julesloisance-wq/aerodoc/blob/main/docs/img/demo.gif) · [Explore the evaluation](https://github.com/julesloisance-wq/aerodoc/blob/main/EXPERIMENTS.md)
